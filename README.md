# Qazaq Words

Локальный тренажёр казахских слов. Требования и последовательность реализации — в [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md).

## Запуск

Требуется Node.js 22.12+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Проверки

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

## Текущий статус

Актуально на 12 октября 2026: доступны локальные профили и гостевые тренировки без сохранения результатов. Словарь поддерживает сортировку, пагинацию и JSON импорт/экспорт; гость может только просматривать его. На главной профиля показаны фото, приветствие и средний прогресс по ступеням слов. Настройки содержат четыре обновлённых стиля: Modern, Retro, Pixel и Orient, четыре палитры, светлую/тёмную/системную тему и размер текста. Dexie использует схему v4; старые настройки Modern New и backup совместимы. Проверены 92 теста и production-сборка. Offline PWA и централизованное обновление словаря из GitHub пока не реализованы. Подробности — в [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md).

Реализованы этапы 1–6: каркас приложения, локальные профили, общий словарь с темами и тренировка с интервальным повторением. Словарь поддерживает добавление, редактирование, подтверждённое удаление, поиск по обоим языкам и фильтрацию по теме. Точные дубли отклоняются; совпадение казахского слова с другим переводом требует подтверждения. Изменение текста атомарно сбрасывает прогресс всех профилей, удаление слова сохраняет исторические ответы. Удаление темы снимает её со слов без сброса прогресса. Схема Dexie версии 1 сохранена без изменения и очистки базы.

Тренировка предлагает ровно четыре уникальных варианта, проверяет ответ автоматически и записывает ответ, прогресс и счётчики одной транзакцией. Очередь содержит все пригодные слова: наступившие повторения, новые слова, затем слова с будущим сроком. После результата можно сразу тренироваться снова с теми же словами. Фильтр темы и ограничение длины сеанса сохраняются. Сеанс и результат восстанавливаются после перезагрузки; уход, смена профиля и изменения словаря требуют подтверждённого прерывания. Клавиши 1–4 работают в карточке вопроса, Enter переводит дальше после результата.

Статистика и показатели главной реализованы. Оформление профиля и полный backup реализованы; offline PWA ещё не реализована. Экраны следующих этапов показывают явно обозначенные пустые состояния. Доменная логика и интеграционные транзакции проверяются тестами; тестовые базы fake-indexeddb не затрагивают пользовательские данные. Словарь изначально пустой, тестовые переводы в приложение не внедряются.

Для статического хостинга требуется SPA fallback на `index.html`.

Перенос словаря доступен на экране «Словарь»: отдельный JSON слов и тем с дополнением существующих записей. Длина сеанса выбирается при подготовке тренировки и сохраняется для профиля. Полный backup с историей доступен в настройках и на экране профиля.

В Настройках доступен размер шрифта: стандартный, +2 px и +4 px. Активность в статистике представлена календарём квадратов; при выборе всего времени календарь охватывает последние 365 дней, показатели и таблица — всю историю.

На странице профилей можно загрузить фото JPG/PNG/WebP до 5 МБ. Квадратная миниатюра хранится локально и переносится вместе с полным backup.

Обновлённое оформление доступно в «Настройки → Стиль → Modern New». Для прежнего вида выберите Modern; оба стиля используют одинаковые данные и тренировки.
