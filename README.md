# Qazaq Words

Локальный тренажёр казахских слов. Требования и последовательность реализации — в [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md).

## Запуск

Требуется Node.js 22.12+ и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Проверки

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

## Текущий статус

Актуально на 13 октября 2026: доступны локальные профили и гостевые тренировки без сохранения результатов. Словарь поддерживает сортировку, пагинацию и JSON импорт/экспорт; гость может только просматривать его. На главной профиля показаны фото, приветствие и средний прогресс по ступеням слов. Настройки содержат четыре обновлённых стиля: Modern, Retro, Pixel и Orient, пять палитр, включая серую, светлую/тёмную/системную тему и размер текста. Dexie использует схему v4; старые настройки Modern New и backup совместимы. Проверены 109 тестов и production-сборка PWA. Offline PWA реализована в ветке feature/pwa; общий словарь автоматически загружается из публичного GitHub. Подробности — в [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md).

Реализованы этапы 1–6: каркас приложения, локальные профили, общий словарь с темами и тренировка с интервальным повторением. Словарь поддерживает добавление, редактирование, подтверждённое удаление, поиск по обоим языкам и фильтрацию по теме. Точные дубли отклоняются; совпадение казахского слова с другим переводом требует подтверждения. Изменение текста атомарно сбрасывает прогресс всех профилей, удаление слова сохраняет исторические ответы. Удаление темы снимает её со слов без сброса прогресса. Схема Dexie версии 4 сохраняет существующие данные через версионные миграции.

Тренировка предлагает ровно четыре уникальных варианта, проверяет ответ автоматически и записывает ответ, прогресс и счётчики одной транзакцией. Очередь содержит все пригодные слова: наступившие повторения, новые слова, затем слова с будущим сроком. После результата можно сразу тренироваться снова с теми же словами. Фильтр темы и ограничение длины сеанса сохраняются. Сеанс и результат восстанавливаются после перезагрузки; уход, смена профиля и изменения словаря требуют подтверждённого прерывания. Клавиши 1–4 работают в карточке вопроса, Enter переводит дальше после результата.

Статистика и показатели главной реализованы. Оформление профиля и полный backup реализованы; offline PWA реализована в production-сборке. Доменная логика и интеграционные транзакции проверяются тестами; тестовые базы fake-indexeddb не затрагивают пользовательские данные. Первый запуск получает встроенный общий словарь (7703 пары, 23 тега), затем проверяет обновления из GitHub. Тестовые переводы в приложение не внедряются.

Для статического хостинга требуется SPA fallback на `index.html`.

Перенос словаря доступен на экране «Словарь»: отдельный JSON слов и тем с дополнением существующих записей. Длина сеанса выбирается при подготовке тренировки и сохраняется для профиля. Полный backup с историей доступен в настройках и на экране профиля.

В Настройках доступен размер шрифта: стандартный, +2 px и +4 px. Активность в статистике представлена календарём квадратов; при выборе всего времени календарь охватывает последние 365 дней, показатели и таблица — всю историю.

На странице профилей можно загрузить фото JPG/PNG/WebP до 5 МБ. Квадратная миниатюра хранится локально и переносится вместе с полным backup.

В «Настройки → Стиль» доступны Modern, Retro, Pixel и Orient.

## PWA: установка и офлайн

```sh
pnpm build
pnpm preview --port 5175
```

Откройте http://127.0.0.1:5175 и дождитесь «Готово к работе офлайн».
Кнопка «Установить приложение» запускает установку в поддерживающем браузере
или показывает инструкции для Chrome/Edge и Safari. После первого полного запуска
кэшируются все страницы, код, стили, иконки и локальные шрифты, включая казахские буквы.
Остановка preview после подготовки кэша позволяет проверить запуск без сервера.
`pnpm dev` специально не регистрирует service worker.

Для использования другими людьми без локального терминала нужна публикация `dist/`
на HTTPS-хостинге. Сам по себе локальный preview не заменяет публикацию.
Для размещения в подпапке можно собрать `pnpm build --base=/qazaq-words/`;
роутер, manifest и service worker используют этот префикс. Хостинг должен отдавать
`index.html` для маршрутов приложения. Настройка GitHub Pages остаётся отдельной задачей; доставка общего словаря из GitHub уже реализована.

Новая версия предлагается кнопкой «Обновить приложение» с подтверждением
перезагрузки. Активную тренировку сначала нужно завершить. Вкладки не
перезагружаются автоматически при обновлении из другой вкладки.
Профили, словарь и история остаются в IndexedDB; обновление кэша их не удаляет.
Очистка данных сайта, другой браузер или другой адрес сайта — отдельное хранилище.
Периодически экспортируйте полный JSON backup.

На телефоне словарь загружается автоматически, в том числе при открытии по LAN HTTP. HTTPS требуется для установки и офлайн-кэша PWA. Профили и результаты остаются отдельными на каждом устройстве; их можно переносить полным JSON backup.

## Автоматический общий словарь

Источник — [imports/general-dictionary.json](https://github.com/alexfoxrussian/qazaq-words/blob/main/imports/general-dictionary.json) в публичном репозитории. Приложение проверяет его при запуске, возвращении сети и далее не чаще раза в час после успешной загрузки. При сбое повторяет попытки с увеличением интервала. На новом устройстве сразу доступна встроенная копия, включая гостевой режим; ручной импорт не нужен.

Обновление только дополняет слова и новые связи с темами. Прогресс, история, активный сеанс и собственные слова сохраняются. Локально удалённые записи и снятые темы не возвращаются при повторной загрузке. Изменённая внешняя пара слово/перевод добавляется как новая; прежняя локальная запись не переписывается. Удаление строки в GitHub не удаляет её на устройствах. Это доставка общего словаря, профили и результаты на сервер не отправляются.

Для другого публичного HTTPS-источника задайте `VITE_DICTIONARY_URL` перед сборкой. Формат — `qazaq-words-dictionary` версии 1; URL должен разрешать CORS. Пароль и GitHub token клиенту не нужны. Снимок первого запуска импортируется непосредственно из `imports/general-dictionary.json`; отдельная копия не требуется. Метаданные загрузки находятся в IndexedDB и включены в полный backup; старые backup принимаются.
